Guide / Tech Notes

Implementation notes remain separate from operational screens.

Client Operations boundary:
Master Catalog creates and publishes client campaign assignments. Client Operations manages the client account, those published assignments, API access, portal access and activation. Raw network IDs, raw network links, network commission and MBO margin are never exposed here as client-facing data.
