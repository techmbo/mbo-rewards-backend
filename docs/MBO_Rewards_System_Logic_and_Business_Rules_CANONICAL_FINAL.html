System Logic & Business Rules

Canonical rules governing how data, decisions and money move between Networks, MBO Rewards and Clients. This document defines the platform's behavior independently of any one network API schema.

Direction 1Network → MBO
Direction 2MBO → Network
Direction 3MBO → Client
Direction 4Client → MBO

1. System Logic Overview

The MBO Rewards platform is the controlled translation and decision layer between networks and clients.

1Network Source

35. Non-Negotiable Rules

These rules must never be bypassed.

1
Never invent source fields or statuses.

Unknown source data goes to review.

2
Never expose network economics to clients.

Network commission, MBO margin and source selection stay internal.

3
Never fake individual orders from aggregate data.

Granularity must match the source.

4
Never treat network-paid as MBO-received automatically.

Receipt is an independent MBO fact.

5
Never attribute ambiguous shared coupons.

Use review when client ownership is uncertain.

6
Never overwrite historical commercial logic.

Keep rule versions.

7
Never allow cross-client access.

Ownership checks apply everywhere.

8
Never combine currencies silently.

Currency is part of every money value.
